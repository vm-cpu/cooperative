# Чернетка карти за фотографіями

Основа реалізації — останній білд PR #9, `a0cab48ab654521b8604909d8e37240ee8835a1d`.
Джерела геометрії — три фотографії паперового плану, надані користувачем
11.11.2026. Фотографії не додаються в репозиторій. Це схематичне перенесення,
не геодезична зйомка й не завершена перевірка кількості та меж боксів.

## Погоджена поведінка

- Перемикач «Список / Карта» в гаражах, спільні пошук і фільтри в URL.
- Початковий напрям — від КПП углиб кооперативу.
- Поворот на 90° в обидві сторони, масштаб, перетягування й клавіатура.
- Підписи компенсують поворот карти й залишаються горизонтальними.
- Спільні оглядові місця підписані «Яма».
- Непрочитані номери — `null`, відображаються як «?», мають стабільний ID місця.
- Після вибору показується повний номер і посилання на існуючу демокартку,
  якщо знайдено рівно один відповідний запис. Нуль збігів означає, що картки
  ще немає. Невідомі номери не отримують вигаданих власників.

## Що потребує звірки

Розбиття довгих внутрішніх смуг на клітинки приблизне. ID позначає місце в
чернетці, а не підтверджений фізичний гараж. За уточнень зберігати існуючі ID,
новим або розділеним місцям призначати нові, не перенумеровувати весь масив.

| Ділянка                 | Позначення в коді            | Що перевірити                                            |
| ----------------------- | ---------------------------- | -------------------------------------------------------- |
| Ряд 2                   | r2-left / r2-right           | Більшість внутрішніх номерів, межі та кількість клітинок |
| Ряд 3                   | r3-left / r3-right           | Номери, червоне коло, положення правління                |
| Ряд 5                   | r5-left / r5-right           | Номери, червоне коло, межі та кількість клітинок         |
| Ряд 6                   | r6-left / r6-right           | Основна нумерація та закреслений кінець                  |
| Згин зовнішнього ряду 9 | east-033 … east-036          | Номери біля згину                                        |
| Нижні кути              | south-001, entry-east-001    | Технічні бокси та їхні номери                            |
| Біля КПП                | pit-1 … pit-4                | Точна кількість і розміщення ям, закреслений бокс поруч  |
| Вся схема               | public/registry/site-plan.js | Прочитані номери також звірити перед реальним обліком    |

Поточний реєстр містить лише 26 вигаданих записів. Наявність боксу на схемі
не означає наявність його картки або відомості про власника. Пошук прізвища
працює лише для наявних тестових карток з однозначною прив’язкою.

Орієнтація зберігається в браузері цього пристрою. Персональні налаштування
для різних облікових записів потребують майбутньої прикладної авторизації.
Масштаб і зміщення зберігаються під час переходів у поточному сеансі сторінки.

## Приймання

1. Гаражі → Карта → поворот ліворуч/праворуч. Номери й назви горизонтальні.
2. Початковий вигляд повертає напрям від КПП; перезавантаження пам’ятає поворот.
3. Знайти `1-01`, вибрати бокс `1-1`, відкрити демокартку й повернутися на карту.
4. Перемкнути на список — пошук зберігається. Скидання фільтрів зберігає режим.
5. Вибрати «?» — показано ID і повідомлення, без переходу до чужої картки.
6. Перевірити «Яма», КПП і правління. Звірити їхні місця з паперовим планом.
7. Перетягування, кнопки масштабу, Tab, стрілки й Enter, телефон і великий текст.
8. `npm run check`, `npm run test:e2e`, axe, скриншоти map-375/map-1280 у CI.

Схему й підписи ще має прийняти користувач. Автоматичні тести перевіряють
поведінку інтерфейсу, але не підтверджують географічну точність.
