# Безпечне середовище розробки

Чекліст налаштування. ✅ — вже зроблено в репозиторії, ☐ — треба зробити вручну (вказано хто).

## 1. Репозиторій (зроблено в коді)

- ✅ `AGENTS.md` — правила для AI-асистентів: спочатку питання й «чого бракує», потім код; безпека; доступність; навчання.
- ✅ CI (`.github/workflows/ci.yml`) на кожен PR: аудит залежностей, lint, формат, тести, перевірка збірки, сканування секретів (gitleaks).
- ✅ Dependabot — щотижневі оновлення залежностей.
- ✅ Шаблони PR і задач з обов'язковим розділом «Чого бракує / відкриті питання».
- ✅ `CODEOWNERS` — кожен PR потребує перегляду власника репозиторію.
- ✅ `.gitignore` блокує секрети (`.env`, `.dev.vars`) і файли з персональними даними (`*.csv`, `*.docx`, `*.xlsx`, `*.pdf`, `data/`, `scans/`).
- ✅ npm 11 з `allowScripts`: install-скрипти пакетів запускаються лише для перевірених (esbuild, workerd) — захист від шкідливих пакетів.

## 2. GitHub (власник репозиторію)

- ☐ **Двофакторна автентифікація (2FA)** на акаунтах власника і Володі: GitHub → Settings → Password and authentication.
- ☐ **Захист гілки `main`**: репозиторій → Settings → Branches (або Rules → Rulesets) → правило для `main`:
  - злиття тільки через pull request;
  - обов'язковий 1 approve (від власника, див. CODEOWNERS);
  - обов'язкові перевірки: `Lint, format, tests, build` і `Secret scan`;
  - заборонити force push і видалення гілки.
- ☐ **Dependabot alerts** і **security updates**: Settings → Code security → увімкнути.
- ☐ **Secret scanning / push protection**: там само, якщо доступно для приватного репозиторію на вашому тарифі.
- ☐ Права Володі в репозиторії — **Write** (не Admin).

## 3. Cloudflare (власник акаунта)

- ☐ **2FA** на акаунті Cloudflare: My Profile → Authentication.
- ☐ Роль Володі — **Workers Admin** (не Super Administrator): доступ до Workers, D1, R2, без оплати й DNS.
- ☐ **Сповіщення**: Notifications → додати email-сповіщення про використання / рахунок (Usage-based billing) і про помилки Worker'а.
- ☐ **API-токени** — тільки з мінімальними правами і для конкретного акаунта; не створювати глобальний API Key. Токен для CI (якщо знадобиться) — зберігати в GitHub → Settings → Secrets.
- ☐ **Окремі середовища**: робоча база `cooperative-db` і окрема база для прев'ю/розробки `cooperative-db-dev` (налаштуємо на кроці B3). Реальні дані — тільки в робочій базі.

## 4. Комп'ютер Володі

- ☐ Node.js 22 LTS, npm 11 (`npm install -g npm@11`), Git, VS Code.
- ☐ GitHub CLI: `gh auth login`; Wrangler: `npx wrangler login`.
- ☐ Пароль/біометрія на комп'ютері, оновлена ОС, шифрування диска.
- ☐ Не зберігати скани й таблиці з персональними даними в папці репозиторію.

## 5. AI-асистент Володі (ChatGPT)

- ☐ Створити в ChatGPT окремий **Project** «Кооператив» і вставити в його інструкції вміст `AGENTS.md`.
- ☐ Якщо використовується Codex або інший агент з доступом до репозиторію — він читає `AGENTS.md` автоматично.
- ☐ Не вставляти в чат з AI токени, паролі, а також реальні ПІБ і телефони — для прикладів використовувати вигадані дані.
- ☐ Перевірити, що в налаштуваннях ChatGPT вимкнено використання розмов для навчання моделей (Settings → Data controls), якщо в розмовах можуть траплятися дані кооперативу.
